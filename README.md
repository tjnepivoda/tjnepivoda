The solution uses **K-Means clustering**, with the Elbow Method and Silhouette Score used to evaluate and justify the optimal number of employee clusters.

### NYC Airbnb Pricing Analytics — Predictive Modeling

Built an interactive analytics application to evaluate Airbnb rental opportunities in New York City. The project combines **multiple regression and classification models** to estimate expected nightly pricing and determine the probability that a property can achieve a nightly rate above a specified threshold.

The application incorporates model evaluation using metrics including **R², Adjusted R², MAE, RMSE, Accuracy, Precision, Recall, F1 Score, and ROC-AUC**.

**Skills:** Python · Regression · Classification · scikit-learn · Gradio · Pandas · Model Evaluation

### Airbnb Density & Housing Market Analysis

Analyzed the relationship between **Airbnb concentration and local housing market conditions** using Airbnb listing data, Zillow housing data, rental indices, and Census housing information.

The project used time-series analysis, geographic visualization, scatter plots, and calculated Airbnb-density metrics to explore whether areas with greater short-term rental activity also experience differences in home-value appreciation and rental prices.
